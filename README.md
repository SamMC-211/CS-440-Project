# CS-440-Project

## Tech Stack

- Javascript Runtime Environment
    - Node.JS
    - Comes with npm (Node Package Manager)
- Frontend Language
    - TypeScript (Version of JavaScript that adds types)
- Package Manager
    - NPM
- Code Bundler / Development Server
    - Vite
- Frontend Framework
    - React


## Steps for starting off this project (Just so you can recreate what I did if oyu ever want to mess around with it on your own)

1. Installed Node.js version v24.7.0 (latest at time of writing this) instructions here https://nodejs.org/en/download
2. Install Vite Build tool using "npm create vite@latest" insturctions here https://vite.dev/guide/

**Selected Prompts**
- Project name: CS-440-Project
- Package name: cs-440-project
- Framework: React
- Variation: TypeScript

3. Following the instructions at the end of the Vite install run "npm install" and "npm run dev" (From within the project directory)
